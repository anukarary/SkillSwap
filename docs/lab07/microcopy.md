# Microcopy diff

Confluence байхгүй тул өөрчлөлтийг энд архивласан. Гурван мөр бүгд `index.html` дотор.

Үгийн тоог хоосон зайгаар салгасан. Цэг, таслал, хашилтыг үгэнд тооцоогүй.

## Error message

Дүрэм: involving the user (Chinchilla Ch. 3, pp. 27–30). Өмнө нь HTTP статус уншигчид хамаагүй тоо байсан. Одоо «Та» гэж хандана.

| | Текст | Үг |
| --- | --- | --- |
| Өмнө | Алдаа ${r.status} | 2 |
| Дараа | Та дахин оролдоно уу. | 4 |

`api()` функц, сервер өөрийн `message` өгөөгүй үед.

## Empty state

Дүрэм: keeping it short. «Хэсэг» болон хашилттай «Хайлт»-ыг хассан.

| | Текст | Үг |
| --- | --- | --- |
| Өмнө | Session алга. “Хайлт” хэсгээс заагч сонгож санал илгээнэ үү. | 9 |
| Дараа | Session байхгүй. Хайлтаас заагч сонгоод санал илгээнэ үү. | 8 |

Миний session хоосон үед.

## Onboarding hint

Дүрэм: reducing cognitive load. Өмнөх өгүүлбэр платформыг тайлбарлаж, дараагийн үйлдлийг хэлдэггүй. Одоо нэг дараагийн алхам: суралцагчаар орж, Франц хэлний цаг захиалах.

| | Текст | Үг |
| --- | --- | --- |
| Өмнө | Оюутнууд ур чадвараа credit-ээр солилцдог платформ. | 6 |
| Дараа | Суралцагчаар орж, Франц хэлний цаг захиалаарай. | 6 |

Нэвтрэх дэлгэцийн эхний мөр.
