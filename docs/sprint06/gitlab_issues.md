## #602 FCM болон Google Calendar симуляци

**Шошго:** tech-debt, integration

`onConfirmed` сануулгыг `notes` жагсаалтад хийнэ, calendar event-ийг объект дээр хадгална. `emit` webhook руу `fetch` хийнэ. Жинхэнэ FCM байхгүй. Google Calendar event үүсгэх, цуцлахад устгах холболт байхгүй. `GET /notifications` энэ симуляцийг буцаана. FR-11, FR-15 ийн бүрэн холболт нээлттэй.

**Хийх ажил:** сануулгыг бодит сувгаар илгээх, баталгаажсан session-ы calendar event-ийг үүсгэж, цуцлахад устгах.
